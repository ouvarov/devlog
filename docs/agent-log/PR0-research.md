## Що вийшло

1. **Ресерч** (`research/tech-research.md`): AI SDK 7 (ESM, Node ≥22, перейменовані API `isStepCount`, `instructions`, `onStepEnd`), агентний цикл через `generateText` + tools + `stopWhen`, безкоштовний Gemini `gemini-3.5-flash-lite`, Nest 12 лише ESM, Drizzle 0.45 стабільний, а 1.0 ще RC, PGlite замість окремого Postgres.
2. **Дизайн** (`DESIGN.md`): агенти тільки читають і повертають пропозицію, запис іде після підтвердження користувачем; submit-tool валідує відповідь, і модель сама виправляється в межах ліміту кроків; 7 PR приблизно на 8 год.
3. **Рев'ю плану**: 17 зауважень, 13 прийнято, 1 відкладено, 3 вирішив Олександр.

## Що не делегував агентам

Ці рішення ухвалив Олександр, агенти лише пропонували варіанти:
- стек (NestJS, Postgres через PGlite, Drizzle);
- лише Gemini, а не кілька провайдерів, бо завдання цього не вимагає;
- мова UI англійська, агенти відповідають мовою користувача;
- видалення і закриття батьківської задачі як у Jira;
- новим задачам статус ставить користувач, за замовчуванням `todo`;
- формула fallback для агента A;
- рішення по зауваженнях рев'ю, де план зачіпав продукт.
